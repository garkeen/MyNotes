## 图的应用

#### 欧拉路径和哈密顿路径

给定一个图，如果存在一个路径，使得图中的所有边都恰好经过一次，那么这就是一个**欧拉路径**；

如果这个路径是一个回路，那么这就是一个**欧拉回路**

1.对于无向图，存在欧拉路径当且仅当：

所有边都在一个连通图内，而且奇度的顶点只有0个或2个

如果是0个，那么该路径一定是欧拉回路

如果是2个，那么该路径一定从一个奇度顶点出发到另一个奇度顶点



2.对于有向图，存在欧拉路径当且仅当：

所有边都在一个弱连通图内，至多一个点出度=入度+1，至多一个点入度=出度+1，其余入度=出度

如果是0个，那么这是一个强连通图，该路径一定是欧拉回路

如果是2个，那么该路径一定从一个出度=入度+1的顶点出发到入度=出度+1的顶点，而且整个图的缩点DAG是一条有向链

注意任意游走一定可以回到起点，但是不一定通过了所有边，所以需要专门的算法 Hierholzer算法 求欧拉路径

```C
vector<int> Hierholzer(const G& g, int start, int E) {
    vector<int>  ptr(g.V(), 0);
    vector<char> used(E, 0);
    vector<int>  S;
    vector<int>  P;

    S.push_back(start);

    while (!S.empty()) {
        int v = S.back();
        int i = ptr[v];

        while (i < g.deg(v) && used[g.id(v, i)]) ++i;

        if (i < g.deg(v)) {
            used[g.id(v, i)] = 1;
            S.push_back(g.to(v, i));
            ptr[v] = i + 1;
        } else {
            P.push_back(v);
            S.pop_back();
        }
    }

    if ((int)P.size() != E + 1) return {};

    for (int a = 0, b = (int)P.size() - 1; a < b; ++a, --b) {
        int t = P[a]; P[a] = P[b]; P[b] = t;
    }

    return P;
}
```

大致逻辑：

先走一个$X_0=start \to X_0$的闭合路径$C_1$ 然后在这个闭合路径上从$X_0$逐个点看有没有有没有点有未使用的边

如果有，从第一个有未使用的边的点$X_1$开始游走，每次走未使用的边，最终一定回到$X_1$ 把这个路径拼到$C_1$变成$C_2$

对$C_2$从$X_1$开始重复操作寻找 $X_2$ 得到$C_3$ 然后反复如此得到$C_4$ ... 直到无法继续寻找到未使用的边

时间复杂度是$O(V+E)$



给定一个图，如果存在一个简单路径，使得图中的所有顶点都恰好经过一次，那么这就是一个**哈密顿路径**；

如果这个简单路径是一个回路，那么这就是一个**哈密顿回路**

判定哈密顿路径的存在是一个NP-Complete问题

#### 最短路径

使用dist数组存储到达这些顶点的目前最优的路径长度

使用prev数组存储到达这些顶点的目前最优的路径的前一个节点 便于回溯构造路径

**1.没有负权边**

Dijstra算法

因为没有负权边 那么多走一个节点路径长度必定增加 就可以按路径前缀做贪心搜索

```C
int Dijkstra(const G &g, int s, int t, int *path) {
    const long long INF = 1LL << 62;
    int V = g.V();
    vector<long long> dist(V, INF);
    vector<int> prev(V, -1);
    vector<char> done(V, 0);

    dist[s] = 0;

    for (int iter = 0; iter < V; ++iter) {
        int u = -1;
        
		//选择dist最小的作为当前确定的最短路径 这里可以使用堆减少复杂度
        for (int v = 0; v < V; ++v)
            if (!done[v] && (u == -1 || dist[v] < dist[u])) 
                u = v;
        
        if (u == -1 || dist[u] == INF) break;   /* 剩下的都不可达 */

        done[u] = 1;
		
		//从这个点开始往外走一步
        for (int e = g.first_edge(u); e != -1; e = g.next_edge(u, e)) {
            int v = g.edge_to(u, e);
            long long nd = dist[u] + g.edge_w(u, e);
            if (nd < dist[v]) {
                dist[v] = nd;
                prev[v] = u;
            }
        }
    }

    if (t != s && prev[t] == -1) return 0;		 /* 不可达 */
    /* 回溯路径 */
    int len = 0;
    for (int u = t; ; u = prev[u]) {
        path[len++] = u;
        if (u == s) break;
    }
    for (int i = 0, j = len - 1; i < j; ++i, --j) {
        int tmp = path[i]; path[i] = path[j]; path[j] = tmp;
    }
    return len;
}
```





**2.有负权边，但是没有负回路**

Bellman-Ford算法

此时多走一个节点路径长度不一定会增加 不能按路径前缀来贪心 

但是按BFS的想法来 每轮走一次 k轮后 我们就一定能保证当前的结果是k步内最优的

```C
int BellmanFord(const G &g, int s, int t, int *path) {
    const long long INF = 1LL << 62;
    int V = g.V();
    vector<long long> dist(V, INF);
    vector<int> prev(V, -1);

    dist[s] = 0;

    /* V-1 轮：每轮所有边松弛一次，对应“最多 V-1 条边” */
    for (int round = 0; round < V - 1; ++round) {
        bool updated = false;
        for (int u = 0; u < V; ++u) {
            if (dist[u] == INF) continue;              /* 前缀不可达 */
            for (int e = g.first_edge(u); e != -1; e = g.next_edge(u, e)) {
                int v = g.edge_to(u, e);
                long long nd = dist[u] + g.edge_w(u, e);
                if (nd < dist[v]) {
                    dist[v] = nd;
                    prev[v] = u;
                    updated = true;
                }
            }
        }
        if (!updated) break;                           /* 已收敛，提前退出 */
    }

    if (t != s && prev[t] == -1) return 0;             /* 不可达 */

    /* 回溯路径 */
    int len = 0;
    for (int u = t; ; u = prev[u]) {
        path[len++] = u;
        if (u == s) break;
    }
    for (int i = 0, j = len - 1; i < j; ++i, --j) {
        int tmp = path[i]; path[i] = path[j]; path[j] = tmp;
    }
    return len;
}
```



**3.有负回路**

此时不存在有限长的最短路径，因为通过一次负回路就可以减少路径权重，可以一直这样使得路径权重变无穷大

如何判定是否有负回路？让BF算法多跑一轮，如果还能更新就算有负回路。为什么？

假设只有一个负环 权重为-n 长度是l<|V|,在这个负环内 两个点的距离每走l轮就会减少n

记d=|V|mod l ，那么距离d个边的两个点在V-1轮理论上走了k轮负环，但是还差一步就可以走到k+1轮负环 

此时两个点在V-1轮的距离是k轮负环的距离 再走一步就会更新为k+1轮负环的距离

多个负环怎么办？只能假设存在两个点 V-1步到V步如果减少了 那么一定多走了一个负环 到底是哪一个需要讨论

对所有负环讨论就行



Floyd-Warshall算法

中间松弛

```C
int fw(int n, int w[n][n], int s, int t, int *path)
{
    const long long INF = 1LL << 62;
    int d[n][n];
    int nxt[n][n];
    /* 1. 初始化距离与后继 */
    for (int i = 0; i < n; i++) {
        for (int j = 0; j < n; j++) {
            d[i][j]   = w[i][j];
            nxt[i][j] = (w[i][j] < INF) ? j : -1;
        }
    }

    /* 2. 三重循环松弛，同时更新后继矩阵 */
    for (int k = 0; k < n; k++) {
        for (int i = 0; i < n; i++) {
            for (int j = 0; j < n; j++) {
                if (d[i][k] + d[k][j] < d[i][j]) {
                    d[i][j]   = d[i][k] + d[k][j];
                    nxt[i][j] = nxt[i][k];      /* 继承 i->k 段的下一跳 */
                }
            }
        }
    }

    /* 3. 不可达 */
    if (d[s][t] >= INF) { path[0] = -1; return -1;}

    /* 4. 通过 nxt 重建路径写入 path */
    int len = 0;
    int cur = s;
    path[len++] = cur;
    while (cur != t) {cur = nxt[cur][t];path[len++] = cur;}
    path[len] = -1;

    return d[s][t];
}
```







#### 最小生成树

在一个带权连通图上寻找边权重和最小的生成树

Kruskal 算法

首先，最小生成树一定包含当前的最短边（A,B）

假设不包含，那么去掉生成树中A->B路径中任意一个边，然后加上（A,B），生成树权重肯定更小

选择后，合并已经链接的点，重复操作

如果有多个最短边怎么办？随便选一个都行

```C
long long Kruskal(const G &g, int *parent) {
    int V = g.V();

    vector<Edge> edges;
    for (int u = 0; u < V; ++u)
        for (int e = g.first_edge(u); e != -1; e = g.next_edge(u, e)) {
            int v = g.edge_to(u, e);
            if (v > u) {
                Edge ed;
                ed.u = u; ed.v = v; ed.w = g.edge_w(u, e);
                edges.push_back(ed);
            }
        }

    sort(edges.begin(), edges.end(),
         [](const Edge &a, const Edge &b) { return a.w < b.w; }); //给所有边预排序 
	
    for (int i = 0; i < V; ++i) parent[i] = i;

    long long total = 0;
    int chosen = 0;

    for (int i = 0; i < (int)edges.size() && chosen < V - 1; ++i) {
        int ru = edges[i].u;
        while (parent[ru] != ru) ru = parent[ru];
        int rv = edges[i].v;
        while (parent[rv] != rv) rv = parent[rv];
		
        if (ru == rv) continue;//父指针判环，可以加上并查集的优化如路径压缩

        parent[rv] = ru;
        total += edges[i].w;
        ++chosen;
    }

    return total;
}
```



Prim 算法

从任意一个点A出发，选择当前点最短的邻边，假设链接到B，可以证明这个最短的邻边（A,B）一定在最小生成树

否则，假设不包含这个边，生成树中A和C链接，A和B不链接，此时B和C一定链接，去掉A和C的链接，再添加（A,B）也是生成树，而且权重肯定更小

选择后，合并已经链接的点，重复操作

```C
long long Prim(const G &g, int *parent) {
    const long long INF = 1LL << 62;
    int V = g.V();
    vector<long long> dist(V, INF);
    vector<char> done(V, 0);

    for (int i = 0; i < V; ++i) parent[i] = -1;

    dist[0] = 0;
    long long total = 0;

    for (int iter = 0; iter < V; ++iter) {
        int u = -1;
        for (int v = 0; v < V; ++v)
            if (!done[v] && (u == -1 || dist[v] < dist[u]))
                u = v;
        if (u == -1) break;

        done[u] = 1;
        total += dist[u];

        for (int e = g.first_edge(u); e != -1; e = g.next_edge(u, e)) {
            int v = g.edge_to(u, e);
            long long w = g.edge_w(u, e);
            if (!done[v] && w < dist[v]) {
                dist[v] = w;
                parent[v] = u;
            }
        }
    }

    return total;
}
```



Borůvka 算法

一个显然的想法是，如果边权重都不相同，那么可以并行使用Prim算法 对所有边出发，都会选到自己最短的邻边，也就是说，最小生成树一定包含全部顶点自己的最短邻边 之后把这些点合并 重复操作

如果有多个最短邻边怎么办？此时你只需要保证并行的选的时候没有成环就行

```C
long long Boruvka(const G &g, int *parent) {
    int V = g.V();
    for (int i = 0; i < V; ++i) parent[i] = i;

    vector<Edge> edges;
    for (int u = 0; u < V; ++u)
        for (int e = g.first_edge(u); e != -1; e = g.next_edge(u, e)) {
            int v = g.edge_to(u, e);
            if (v > u) {
                Edge ed;
                ed.u = u; ed.v = v; ed.w = g.edge_w(u, e);
                edges.push_back(ed);
            }
        }

    long long total = 0;
    int components = V;
    vector<int> best(V, -1);   /* best[根] = 该分量当前最小出边的下标 */

    while (components > 1) {
        for (int i = 0; i < V; ++i) best[i] = -1;

        /* 每条边更新两端分量的最小出边 */
        for (int i = 0; i < (int)edges.size(); ++i) {
            int ru = edges[i].u;
            while (parent[ru] != ru) ru = parent[ru];
            int rv = edges[i].v;
            while (parent[rv] != rv) rv = parent[rv];

            if (ru == rv) continue;

            if (best[ru] == -1 || edges[i].w < edges[best[ru]].w)
                best[ru] = i;
            if (best[rv] == -1 || edges[i].w < edges[best[rv]].w)
                best[rv] = i;
        }

        /* 加入每个分量选中的边；同一条边可能被两端同时选中，靠父指针判重 */
        for (int i = 0; i < V; ++i) {
            if (best[i] == -1) continue;
            int idx = best[i];
            int u = edges[idx].u, v = edges[idx].v;

            int ru = u;
            while (parent[ru] != ru) ru = parent[ru];
            int rv = v;
            while (parent[rv] != rv) rv = parent[rv];

            if (ru == rv) continue;

            parent[rv] = ru;
            total += edges[idx].w;
            --components;
        }
    }

    return total;
}
```

#### DAG，AOE和AOV

无向图判环 怎么办？

可以用DFS看当前节点是否访问到已经访问的节点 但是从当前节点来的上一个节点不算 这里使用并查集实现

```C
bool hasCycle(const G &g) {
    int n = g.V();
    vector<int> p(n);
    for (int i = 0; i < n; ++i) p[i] = i;

    for (int u = 0; u < n; ++u) {
        for (int i = 0; i < g.deg(u); ++i) {
            int v = g.neighbor(u, i);
            if (u > v) continue;

            int a = u;
            while (p[a] != a) a = p[a];
            int b = v;
            while (p[b] != b) b = p[b];

            if (a == b) return true;
            p[a] = b;
        }
    }
    return false;
}
```

有向图判环 怎么办？

因为DAG去掉一个源节点依旧是DAG 所以判定一个有向图有没有环 可以使用‌Kahn 算法

每次去掉有向图一个源节点 继续在剩下的图寻找源节点

如果剩下的图非空而且不存在源节点 那么这个图必定有环

```C
bool kahn(const G &g, vector<int> &topo) {
    int n = g.V();
    vector<int> indeg(n, 0);

    for (int u = 0; u < n; ++u)
        for (int i = 0; i < g.outDeg(u); ++i)
            ++indeg[g.outNeighbor(u, i)];

    topo.clear();
    topo.reserve(n);
    for (int u = 0; u < n; ++u)
        if (indeg[u] == 0) topo.push_back(u);

    // topo 同时当队列：前部已定序，后部待扩展
    for (int h = 0; h < (int)topo.size(); ++h) {
        int u = topo[h];
        for (int i = 0; i < g.outDeg(u); ++i) {
            int v = g.outNeighbor(u, i);
            if (--indeg[v] == 0) topo.push_back(v);
        }
    }

    if ((int)topo.size() != n) {
        topo.clear();
        return false;
    }
    return true;
}
```

如果没有环 那么这就是DAG 而且按源节点去掉的先后顺序排列 就是DAG的**拓扑序**



生活中有需要时间不一样的活动 这些活动也有依赖次序 理论上活动可以当顶点 边代表依赖关系 活动也可以当边 节点表示状态

活动当顶点的图叫做AOV 一般假设AOV是一个DAG 否则活动将无法进行

活动当边的图叫做AOE 一般假设不同的活动可以并行

**最少完成时间**

要想知道这些活动的最少完成时间 只需要这样想：每个活动每时每刻都在尝试开始和运行 那么这些活动肯定是按**拓扑序**运行 

而且一个节点的**开始时刻**肯定就是依赖的全部节点**完成时刻**最晚的时候

```C
long long earliestFinish(const G &g, const vector<int> &topo) {
    int n = g.V();
    vector<long long> ve(n, 0);   // ve[u]：事件 u 的最早发生时间

    for (int k = 0; k < (int)topo.size(); ++k) {
        int u = topo[k];

        for (int i = 0; i < g.outDeg(u); ++i) {
            int v = g.outNeighbor(u, i);
            long long w = g.outWeight(u, i);
            // 活动 u->v 最早完成时间 = ve[u] + w ，事件 v 要等所有入边活动都完成，所以取 max
            if (ve[u] + w > ve[v]) 
                ve[v] = ve[u] + w;
        }
    }

    long long ans = 0;
    for (int u = 0; u < n; ++u)
        if (ve[u] > ans) ans = ve[u];

    return ans;
}
```



**关键路径**

求最早完成时间 每个节点的时刻本质上是 **最早开始时刻** 而且事实上这些节点

有了最早完成时间 我们就可以推出每个节点理论上 为了达到最早完成时间 的 **最晚开始时刻**

一个节点的 最早开始时刻 = 最晚开始时刻 就是关键节点 两个关键节点组成的活动就是**关键活动**

一个路径上如果都是关键活动 那么这个路径就是**关键路径**
