## 自由线性表

### 顺序存储

**静态顺序表**

是长度固定的顺序表

建立

```C
typedef struct {
    ElemType data[MAXSIZE];   // 静态数组存放元素
    int length;               // 当前表长
} SList;
```

插入 O(n)

需要提前判定会不会溢出，会溢出之前拒绝插入

查找 O(n)

删除 O(n)

**动态顺序表**

初始固定容量，插入的时候，如果空间不足，会申请更大的连续空间扩容 

是vector的实现基础

建立

```C
typedef struct {
    ElemType *data;           // 指向动态分配的数组
    int length;               // 当前表长
    int maxSize;              // 当前容量
} DList;
```



插入 O(n)

需要提前判定会不会溢出，会溢出那么提前申请更大的空间迁移

查找 O(n)

删除 O(n)



### 链式存储

**动态链表**

即基于动态分配（malloc / new）的链表，通过指针来连接前后节点。

一般来说，链表有三个维度可以选择：

1. 带不带**头节点**？带不带**尾指针**？有没有头结点不会影响时间复杂度，但是有没有尾指针确实会影响

2. **方向**是单向还是双向？
3. **循环**还是不循环？

单向节点

```C
typedef struct LNode {
    ElemType       data;   // 数据域
    struct LNode  *next;   // 指针域，指向后继
} LNode;
typedef struct {
    LNode *head;      // 头指针，指向头节点(或者哨兵节点)
    //LNode *tail;      [可选]尾指针，指向尾节点
    int    length;
} LinkList;
```

双向节点

```C
typedef struct DNode {
    ElemType        data;  // 数据域
    struct DNode   *prev;  // 指向前驱
    struct DNode   *next;  // 指向后继
} DNode;
typedef struct {
    DNode *head;      // 头指针，指向头节点(或者哨兵节点)
    //LNode *tail;      [可选]尾指针，指向尾节点
    int    length;
} LinkList;
```





**静态链表**

使用数组实现链表，指针变成数组的下标。需要维护**数据链表**和**备用链表**。

建立

```C
typedef struct {
    ElemType data;         // 数据域
    int      next;         // 游标：后继节点的数组下标，-1 表示 NULL
} SNode;
typedef struct {
    SNode node[MAXSIZE];   // 节点数组
    int   head;            // 数据链表头游标：指向第一个有效节点，-1 为空
    int   avail;           // 备用链表头游标：指向第一个空闲节点，-1 为无空闲
    int   length;          // 数据链表当前元素个数
} SLinkList;
```

#### 链式存储

##### 链式栈

如果链表头存储栈底 链表尾存储栈顶

那么在链表尾部入栈/出栈 那么时间复杂度是O(n) 低效

所以实际上链表头会存储栈顶 链表尾存储栈底

那么在**链表头部**实现入栈/出栈 时间复杂度都是O(1)



#### 数学性质

卡特兰数 $\frac{1}{n+1}C_{2n}^{n}$

一个排列是合法出栈序列（当入栈为 1..n 时）当且仅当它不包含**312 模式**
