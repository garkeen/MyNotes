### 比赛树（选择树）

堆删除需要下浮，下浮每层需要比较两次（比较左右节点，再比较父子节点），能不能只比较一次？这就是比赛树。

比赛树是完全二叉树，使用数组存储，只有叶子节点是保存值的，分支节点保存胜者/败者的索引。

这个完全二叉树不一定是完美二叉树，可以选择补无穷，也可以选择显式记入叶子节点的开始和结尾。 

由于叶子个数固定，所以比赛树只有一个操作：**更新叶子节点的值，然后更新树**

比赛树相比于堆，每层比较一次，代价就是叶子节点固定为k，而且需要额外存储k-1个节点。

**胜者树**

胜者树的根节点存储最终胜者。

初始化：自底向上，从叶子开始，每层两两比较，胜者存入父结点。

```C
/* 
 * 约定：K 为叶子数（可为任意 >=2 的整数，不要求 2 的幂）；
 *       叶子下标 K..2K-1；内部结点 1..K-1；
 *       val[] 存叶子值；a[] 为树数组。
 *       胜者树：a[1..K-1] 存胜者下标，a[0] 存冠军；
 *       败者树：a[1..K-1] 存败者下标，a[0] 存冠军。
 *       比较规则：值小者胜；相等时下标小者胜。
 */

void winner_init(int K, int *val, int *a)
{
    int i;
    for (i = K; i < 2 * K; i++) a[i] = i;
    for (i = K - 1; i; i--)
        a[i] = val[a[2*i]] <= val[a[2*i+1]] ? a[2*i] : a[2*i+1];
    a[0] = a[1];
}
```

更新节点：更新值需要自底向上的和**兄弟节点记录的胜者**比较，更新父节点，直到不需要继续更新。

```C

        if (a[p] == w) break;
        a[p] = w;

    a[0] = a[1];
```

**败者树**

败者树的根节点存储最后一轮的败者，根节点上还有一个节点存储最终胜者。

初始化：自底向上，从叶子开始，每层两两比较，败者存入父结点，胜者**临时存储**用于下一轮比较。

```C
int loser_build(int K, int *val, int *a, int i)
{
    int l, r;
    if (i >= K) return i;
    l = build(K, val, a, 2*i);
    r = build(K, val, a, 2*i+1);
    if (val[l] <= val[r]) { a[i] = r; return l; }
    else                  { a[i] = l; return r; }
}

void loser_init(int K, int *val, int *a)
{
    int i;
    for (i = K; i < 2*K; i++) a[i] = i;
    a[0] = build(K, val, a, 1);
}
```

更新节点：

这里分两种情况，一种是只更新最终胜者，一种是更新任意节点。

只更新最终胜者需要自底向上的和**父节点记录的败者**比较，更新父节点，一直更新到根节点。

```C
/* 只更新当前冠军叶子：O(log K) 时间，O(1) 额外空间 */
void loser_update_champion(int *val, int *a, int leaf, int v)
{
    int s, p, t;
    val[leaf] = v;
    for (s = leaf, p = leaf >> 1; p; p >>= 1)
        if (val[s] > val[a[p]] || (val[s] == val[a[p]] && s > a[p])) {
            t = s; s = a[p]; a[p] = t;
        }
    a[0] = s;
}
```

```C
/* 更新任意叶子：O(log K) 时间，O(log K) 额外空间。
 * 不要求 K 是 2 的幂；用完全二叉树数组表示，叶子的二进制路径
 * 判断目标在每一层的左/右方向。
 */
void loser_update_any(int K, int *val, int *a, int leaf, int v)
{
    int H = 0, temp = 2 * K - 1;
    int path[64], opp[64], d = 0;
    int cur, p, Lleaf, Lcur, cur_dir, leaf_dir, s, t;

    while ((temp >>= 1)) H++;          /* H = floor(log2(2K-1)) */
    val[leaf] = v;
    cur = a[0];
    p = 1;
    Lleaf = (leaf >> H) ? H + 1 : H;

    while (p < K) {
        Lcur = (cur >> H) ? H + 1 : H;
        cur_dir  = (cur  >> (Lcur  - 2 - d)) & 1;
        leaf_dir = (leaf >> (Lleaf - 2 - d)) & 1;

        path[d] = p;
        if (cur_dir == leaf_dir) {
            opp[d] = a[p];             /* 对手在另一侧：败者 */
        } else {
            opp[d] = cur;              /* 对手就是当前胜者 */
            cur = a[p];                /* 进入目标侧，该侧胜者是败者 */
        }
        p = (p << 1) | leaf_dir;
        d++;
    }

    s = leaf;
    for (t = d - 1; t >= 0; t--) {
        p = path[t];
        if (val[s] > val[opp[t]] || (val[s] == val[opp[t]] && s > opp[t])) {
            a[p] = s;
            s = opp[t];
        } else {
            a[p] = opp[t];
        }
    }
    a[0] = s;
}
```



可以用于多路归并排序
