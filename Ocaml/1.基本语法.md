## 变量的本质以及变量重命名

函数式语言，变量只是指向值的某种指针，其形式只用于与其他变量区分，也就是说

x + y 和 a + b是同一个意思

x + x 和 y + y是同一个意思

但是x + x和x + y不是同一个意思

可以把局部scope的变量重命名 然后把let看成全局作用



函数式语言没有赋值运算符 根本上确定了变量是一次性赋值的 因此=号就是判断是否相等

那么我可以写两次

let x = 1;;

let x = 2;;

不会报错 因为这等价于

let x = 1 in (let x = 2 in (....))

思考

考虑一个循环，里面的变量被不断赋值，但是，我们知道，函数式语言不能这样，那么，这意味着我们重复一个过程

每次都必须申请新的内存空间储存新的值，换句话说，我们相当于用递归实现循环，递归本质上就是不断申请新空间实现一个过程

那么，垃圾回收变得史无前例的重要，单单一个循环就需要循环次数大小的内存空间，这和命令式语言完全不同，命令式语言只要一个变量空间就行，反复使用

定义式不是表达式，还是考虑一个循环，里面的循环变量会被不断赋值，那么显然不可以实现循环中的循环变量，但是一个循环等价于一个递归

## 匿名函数

本质上就是直接给出函数的输入与输出的关系并通过->连接 作为一个函数表达式 

这个东西就是匿名函数 就是没有名字的函数

(fun x->x+1)就是一个匿名函数

(fun x->x+1) 1

=>2





函数应用 apply

## 递归函数

递归是通过

1.先定义一个递归函数

2.然后对这个递归函数不断求值

实现的

函数理论上可以间接递归或者直接递归

间接递归 t(x)=h(f(x)) 然后 f(x)=g(t(x)) 等价于这样定义f(x)=g(h(f(x))) t(x)=h(g(t(x)))

直接递归 f(x)=g(f(x))

显然 前者违反了先定义后使用的规则 可以直接发现 后者可以通过查询是否使用了定义发现

需要显式使用rec关键字告诉编译器我在定义一个递归函数

let rec **fact** x = (fun x -> if x = 1 then 1 else x * **fact**( x -1) )
