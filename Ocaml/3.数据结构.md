## 变体Variants

相当于枚举类型

type some_color = Red | Blue | Yellow;;

let c = Yellow;;

注意我们不需要指定c的类型是some_color 直接赋值就行

Red， Blue ，Yellow是值，类型为color

而且Red， Blue ，Yellow也是构造器，但由于没有输入，是无参构造器



使用of关键字可以携带数据

type shapes = 

| Circle of point * float

| Rectangle of point * point ;;

let ac =Circle (0.,0.) * 4.

其中 ac的类型是shapes 值就是 Circle (0.,0.) * 4. 也就是说 值里面既包含构造器名字 又包含参数值

所以 构造器Constructor也被看成是标签Tag

# 函数式数据结构

我们知道函数式编程的所谓变量本质上是不可变的，那么每次你的新值要么赋予另一个不同名变量，要么是保留在表达式中

比如求和，所有的中间值都是过程值，没有绑定在某个变量上，都是在一个过程式的求值表达式里面

sum(1,sum(2,sum(3,0)))



由于函数式编程没有副作用，程序员必须在每次调用一个操作后用新变量接收新的数据结构，比如

let newstack=push(x,oldstack)
