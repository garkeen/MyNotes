# 代数数据类型 Algebra Data Types

事实上，Ocaml的变体就是代数数据类型 

和 积

## 递归类型

比如，我们在定义变体类型的时候，可以递归定义

type **intlist** =

| Nil

| Cons of int * **intlist**



## 参数化变体类型

type 'a mylist =

| Nil

| Cons of 'a * 'a mylist



事实上，列表就是用这个操作定义的



这种带参数的类型可以被称为以‘a为参数的类型构造器，Nil和Cons都是其构造器



## Options类型

type 'a option = 

None | Some of 'a

这完全是用变体定义的



Option.map



Option.bind

## Exn类型

是可以扩展的变体类型 也就是我们不是一次性把exn的所有类型定义好 而是可以添加

怎么添加？通过exception关键字添加

比如，exception OhNo string;;

那么OhNo string就是exn类型的值，其中OhNo是构造器，string是参数

标准库提供raise函数主动触发异常



## Try表达式

try e with

|p1 -> e1

|p2 ->e2

如果e的求值不出现异常那么直接返回e的值

否则根据e的异常来进行模式匹配
