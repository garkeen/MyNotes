# 引用

一个引用变量指向固定的内存地址，但是这个内存地址的内容是可以变的

其实按这种操作，引用才是C++的变量，而变量是C++的const修饰的常量

注意，引用一旦定义那么这个引用变量的类型就确定了，就像你强制只能用int解释内存某块地址内容一样

### 定义引用

let x = ref 42;;

x:=43;;

### !解引用

(!x)+3;;



### 序列运算符；

e1;e2

等价于
let ()=e1 in e2

如果e1不具有类型unit 那会出现类型错误



### 变量别名

### 相等

==表示物理相等 引用的地址是否一样



<>表示结构相等 也就是最后求值的结果是否一样

## 引用的实质

是通过mutable关键字实现的

type 'a ref = {mutable contents:'a}

let ref x = {contents = x}

let (!) r = r.contents

let (:=) r newval = r.contents <- newval
