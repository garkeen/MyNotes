使用struct end

显然 注意，ModuleName是一个模块，struct ... end是这个模块的**值**

比如

module AnotherModule = ModuleName



如果一个表达式里面使用的函数和变量都是同一个模块 那么可以使用

ModuleName.f ModuleName.g ModuleName.h ModuleName.x

## 模块类型

module type TypeName = **sig**

​	specifications

val  fact: int -> int

**end**

如果一个模型具有模型类型TypeName，那么里面**必须存在名字叫fact的值**

而且这个值**必须具有类型int->int** 也就是说fact是int到int的函数



如果模块定义了其类型签名里面定义的东西**之外**的辅助函数或者值，那么这些值不会暴露

如果模块不具有类型，那么所有模块定义的值都默认可以被暴露



## 签名检测

如果模块具有模块类型T，那么模块里面的变量-类型必须符合规范

注意，假如一个函数的的类型是

'a -> 'a

那么如果T定义的是int -> int 那么不会有错误



## 抽象类型

签名是一切能被暴露的东西 

比如

type 'a stack

val empty:'a stack

val add: 'a ->'a stack -> 'a stack

impl:

type 'a stack = 'a list

因此就算你知道签名里面stack的实现只不过是list的别名 

但是如果签名没有明显的暴露这一点 那么你也不能直接使用列表来初始化一个类型为stack的变量

因为编译器不知道stack到底是什么 但是编译器知道有哪些接口 所以

let s1:int stack = empty |> push 4 可以

let s2:int stack = [4,3,2,1] 不行

type 'a stack被称为抽象类型
