# 模式匹配

### 本质是表达式

一个可以求值的表达式 根据输入来判定赋予什么值

match X with

| A -> a

| B -> b

| _ -> default

求值可以得到a

其中 A B _ 被称为**模式Pattern**

 X A B 类型必须一样

a b ...类型必须一样

## 模式

如果模式出现了变量那么可以被匹配为任何东西并**绑定**（也就是赋值给这个变量） 就像解析器一样

如果模式出现了通配符那么可以匹配为任何东西但不绑定



## 顺序

match会按顺序匹配并返回第一个匹配的结果

function关键字

let f x y z = 

match z with

| p1 -> e1

| p2 -> e2

等价于
let f x y = function

| p1 -> e1

| p2 -> e2
