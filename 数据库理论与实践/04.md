### 元组关系演算

| 原子表达式  | 含义                                                         |
| ----------- | ------------------------------------------------------------ |
| R(t)        | 关系 `R` 中存在元组变量 `t`，相当于 t ∈ R                    |
| t[i] θ u[j] | 元组变量 `t` 的第 `i` 个分量与元组变量 `u` 的第 `j` 个分量通过算术比较运算符 `θ` （如 >，<，=）比较 |
| t[i] θ C    | 元组变量 `t` 的第 `i` 个分量与常量 `C` 通过算术比较运算符 `θ` 比较 |

设A,B,C是原子表达式，那么

| 符号表达式                        | 含义                                                         |
| --------------------------------- | ------------------------------------------------------------ |
| A ∧ B                             | 逻辑与：表示两个条件都要满足                                 |
| A ∨ B                             | 逻辑或：表示至少一个条件满足                                 |
| ¬A                                | 逻辑非：表示条件 `A` 不满足                                  |
| ∃u(R(u)∧A(t,u))                   | 存在量词：表示存在一个元组 `u` 属于关系 `R`，使得条件 `A(t,u)` 成立 |
| ∀u(R(u)∧A(t,u))=¬∃u(R(u)∧¬A(t,u)) | 全称量词：表示对于所有元组 `u` 属于关系 `R`，条件 `A(t,u)` 都成立 |

的任意有限组合都是演算表达式,但是注意！对于任意元组，我们必须定义，否则无意义。

比如t[2]>s[3]是一个无意义的表达式，我们不知道t和s是什么关系的元素。

(∃u)u[1]=2有意义吗？看起来好像定义了u，但是这个∃符号就很难崩，按照集合论角度(∃u)与(∀u)必须携带定义域,**在不同的域这个表达式的值可能不同**，为了计算一定要指定定义域
$$
(∃u)u[1]=2，如果u\in \{<1,2>,<2,2>\},那么值T \newline
(∃u)u[1]=2，如果u\in \{<3,2>,<2,2>\},那么值F
$$
{t|t=2∨t=3}有意义吗？虽然没有指定t从哪里取得，但是我们知道这个集合就是
$$
\{2，3\}
$$
{t|t∈R}有意义吗？显然这就是R ，事实上等价于
$$
\{t|t=r_1∨t=r_2...\or t=r_n\},其中r_1 ... r_n是R中的所有元素
$$
因此，本质上我们求T就是把一个完全确定可计算的演算表达式化简为
$$
\{t|t=a∨t=b\or...\or t=z\} \newline 也就是 \newline \{a,b,...,z\}
$$


| 关系代数运算              | 元组关系演算表达式                                           |
| ------------------------- | ------------------------------------------------------------ |
| 并 `(R ∪ S)`              | `{ t | R(t) ∨ S(t) }`                                        |
| 交 `(R ∩ S)`              | `{ t | R(t) ∧ S(t) }`                                        |
| 差 `(R - S)`              | `{ t | R(t) ∧ ¬S(t) }`                                       |
| 笛卡尔积 `(R × S)`        | `{ t | (∃u)(∃v)(R(u) ∧ S(v) ∧ t[1] = u[1] ∧ ... ∧ t[r] = u[r] ∧ t[r+1] = v[1] ∧ ... ∧ t[r+s] = v[s]) }` |
| 笛卡尔除 `(R ÷ S)`              | `{ t | T=π_{r-s}(R)∧T(t)∧(∀s)(S(s)∧R(<t,s>) }` |
| 投影`(π_{i1,i2,…,ik (R))` | `{ t | (∃u)(R(u) ∧ t[1] = u[i1] ∧ ... ∧ t[k] = u[ik]) }`     |
| 选择 `(σ_F(R))`           | `{ t | R(t) ∧ F }`                                          |
| 存在 `(∃t)R(r)∧F(t,r)`           | `{ t | (∃r)R(r) ∧ F(r,t) }`                                          |
| 任意 `(t)∀R(r)∧F(t,r)`           | `{ t | (∀r)R(r) ∧ F(r,t) }`                                          |

现在一个任务就是把任何元组的关系演算表示为



```
select x from y where z
```

的形式，或者说是
$$
\pi_{x}(σ_z(y))
$$

我们接下来把原子表达式和符合表达式一个个转换成select语句就行了
| 关系代数运算              | sql语句                                    |
| ------------------------- | ------------------------------------------------------------ |
| 并 `(R ∪ S)`              | R union S                           |
| 交 `(R ∩ S)`              | R intersact S            |
| 差 `(R - S)`              | select r from R where not exists (select 1 from S where s.c=r.c) |
| 笛卡尔积 `(R × S)`        | select * from R join S |
| 笛卡尔除 `(R ÷ S)`        | select * from (select r-s from  R) as P where  任意 |
| 投影`(π_{i1,i2,…,ik (R))` | select 1 2 3 ... from R |
| 选择 `(σ_F(R))`           | select * from R where F |
| 存在 `(∃t)R(r)∧F(t,r)`           | select * from R where exists (select 1 from R where F(t,r)) |
| 任意 `(t)∀R(r)∧F(t,r)`           | select * from R where not exists (select 1 from R where not F(t,r)) |
