### 关系代数

三种数据结构：

set 集合 无序，去重

bag 包 无序集合，不去重

list 列表 有序





**超键**：任何可以唯一标识每一行的 属性集，一个表可以有很多超键

**候选键**：是超键，但是其中没有多余属性（属性集内不存在一个属性，去掉这个属性依然能唯一标识），一个表可以有很多候选键

**主键**：是一个候选键，也就是一个属性集，唯一一个被选用于区分每一行的键，一个表**只能有**一个主键

**外键**：是一个属性集，是其他关系的主键，一个表可以有多个外键

集合论上的关系

$$
{集合:} S_1, S_2, S_3, \ldots, S_n  \\
{n元组:} t = (e_1, e_2, e_3, \ldots, e_n) ,e_x\in S_x \\
{n元关系:} \text{集合} R, t \in R
$$
关系代数首先满足交，并，差，乘，除的运算，但是运算结果不一定是关系，因此需要注意限制
$$
并集：R \cup S≡\{ t︱t∈R \or t∈S \} \newline
交集：R \cap S≡\{ t︱t∈R \land t∈S \} \newline
差集：R-S≡\{ t︱t∈R∧t \ne S \} \newline
其中，R与S的每个属性都是一一对应的,显然有 \newline
R \cap S≡R-(R-S) \newline
$$
专门属于关系的乘除运算，
$$
笛卡尔乘积：R×S ≡\{ t︱t=<t^r,t^s>∧t^r∈R∧t^s∈S \} \newline
笛卡尔除法：R÷S≡\{ t︱t=t^{r-s},(t^{r-s}×S)\subseteq R \} \newline
注意(R÷S)× S \not \equiv R,因为R中可能存在无法整除S的元素，相当于余数
$$

---------------连接-------------- \newline
内连接(自然连接):R \bowtie S \equiv \sigma _{R与S所有公共属性一一相等}  (R×S) \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \newline 
左外连接：R  = \bowtie \ \ \   S \equiv \sigma _{R与S所有公共属性一一相等,或R中没有一个公共属性与S相等}  (R×S)\newline
右外连接：R   \ \ \ \bowtie =S \equiv \sigma _{R与S所有公共属性一一相等,或S中没有一个公共属性与S相等}  (R×S)\newline
全外连接：R  = \bowtie = S \equiv 左外连接+右外连接\ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \newline
