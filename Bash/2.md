# 外部命令

## 文件与目录操作

**`ls`**：列出目录内容。

**`cp`**：复制文件或目录。

**`mv`**：移动或重命名文件。

**`rm`**：删除文件或目录。

**`mkdir`**：创建目录。

**`rmdir`**：删除空目录。

**`touch`**：更改文件时间戳或创建空文件。

**`ln`**：创建硬链接或符号链接。

**`chmod`**：更改文件权限。

**`chown`**：更改文件所有者。

**`chgrp`**：更改文件所属组。

**`df`**：查看磁盘分区使用情况。

**`du`**：估算文件/目录的磁盘使用空间。

**`dd`**：转换和复制文件（常用于磁盘操作）

**`tree`**：以树状图列出目录结构（需单独安装，但很常见）

## 文本处理

**`cat`**：连接文件并打印到标准输出。

**`less`** / **`more`**：分页查看文件内容。

**`head`**：输出文件开头部分。

**`tail`**：输出文件末尾部分（常用 `tail -f` 实时监控日志）。

**`grep`**：强大的文本搜索工具。

**`awk`**：模式扫描和处理语言（文本处理三剑客之一）。

**`sed`**：流编辑器（文本处理三剑客之一）。

**`cut`**：从每行移除（选取）特定字段。

**`sort`**：对文本文件进行排序。

**`uniq`**：报告或忽略重复行。

**`wc`**：统计行数、单词数、字节数。

**`diff`**：逐行比较文件差异。

**`patch`**：将 diff 文件应用到原文件。

**`tr`**：替换或删除字符。

**`echo`**：输出文本。（**注意**：`echo` 既是 Shell 内置命令，也有外部命令 `/bin/echo`，通常内置优先级更高）

## 文件查找，压缩

**`find`**：在目录树中查找文件（极其强大）

**`locate`**：通过数据库快速查找文件（需 updatedb）

**`tar`**：磁带归档工具（打包/解包 .tar 文件）

**`gzip`** / **`gunzip`**：GNU 压缩/解压工具

**`zip`** / **`unzip`**：处理 .zip 格式文件

**`xargs`**：从标准输入构建并执行命令行（常与 find 搭配）

## 系统状态与监控

- **`ps`**：报告当前进程快照。
- **`top`** / **`htop`**：显示 Linux 进程（动态监控）。
- **`kill`**：终止进程（发送信号）。（**注意**：`kill` 有内置命令，也有外部命令 `/bin/kill`）
- **`free`**：显示内存使用情况。
- **`uptime`**：显示系统运行时间、用户数、负载。
- **`uname`**：打印系统信息（内核版本、主机名等）。
- **`dmesg`**：打印或控制内核环形缓冲区（通常查看启动信息）。
- **`lsof`**：列出打开的文件（排查问题的神器）。
- **`vmstat`**：报告虚拟内存统计。
- **`iostat`**：报告 CPU 统计和设备与分区的 I/O 统计

## 网络命令

- **`ping`**：发送 ICMP 请求测试网络连通性。
- **`ifconfig`**：**过时**，配置网络接口（现在很多用 `ip` 命令替代）
- **`ip`**：现代 Linux 的网络配置工具（`ip addr`, `ip link` 等）
- **`netstat`**：**过时**，打印网络连接、路由表等（现在常用 `ss`）
- **`ss`**：更现代、更快的 socket 统计工具，替代 `netstat`
- **`curl`** / **`wget`**：传输数据的工具（常用于下载文件、测试 API）
- **`ssh`**：OpenSSH 远程登录客户端
- **`scp`** / **`sftp`**：基于 SSH 的文件传输
- **`traceroute`**：追踪网络路由路径
- **`nslookup`** / **`dig`**：DNS 查询工具
- **`hostname`**：显示或设置系统主机名



## 用户与权限管理

- **`who`** / **`w`**：显示谁登录了以及他们在做什么。
- **`useradd`** / **`userdel`** / **`usermod`**：添加/删除/修改用户。
- **`groupadd`**：添加组。
- **`passwd`**：更改用户密码。
- **`sudo`**：以超级用户或其他用户身份执行命令。
- **`su`**：切换用户身份。



### 软件开发与编译

- **`make`**：自动化编译工具。
- **`gcc`** / **`clang`**：C/C++ 编译器。
- **`git`**：版本控制系统。
- **`ldd`**：打印共享库依赖。

## 其他常见工具

- **`man`**：查看手册页（最重要的命令之一）。
- **`date`**：打印或设置系统日期时间。
- **`cal`**：显示日历。
