#### ...<=lnx<=...

$x\to\infty$，$\ln x$的增长率小于一切多项式 $\ln x<x^a\ (a>0)$，因此$x\to\infty$下，不要寻求一个多项式或者多项分式$F$，使得$F<\ln x$，除非$F<constant$；当然，$x\to\infty$下，$\ln x$的上界可以取任意的$x^a$，只要$a>0$

$x\to 0$，$\ln x$的增长率（或者说，下降率）如何讨论？毕竟这和上面$x$增长到无穷的情形是不一样的。一个好的想法是通过某种变换把$x\to 0$同尺度的变成$x\to\infty$，最经典的就是使用倒代换，这样我们就可以讨论$x\to\infty$，$\ln(1/x)$的增长速度，先把负无穷变成正无穷，就是讨论$-\ln(1/x)$的速度在$x\to\infty$的速度，所以就是讨论$\ln x$在$x\to\infty$的速度，有

$$\ln x < x < e^x$$

所以

$$\ln(1/x) < 1/x < e^{1/x}$$

所以

$$-\ln x < 1/x < e^{1/x}$$

所以

$$-e^{1/x} < -1/x < \ln x$$

事实上我们可以发现，构造一个$1\to 0$趋近负无穷，但是大于$\ln x$的函数$F$，和构造$1\to+\infty$趋近正无穷，但是小于$\ln x$的函数$G$，是一样难的

#### ....<= x! <= ....

斯特林公式

$$n!=\sqrt{2\pi n}\left(\frac{n}{e}\right)^n e^{\delta},\quad 0<\delta<\frac{1}{12n}$$

由$0<\delta<\frac1{12n}$直接得

$$\sqrt{2\pi n}\left(\frac{n}{e}\right)^n < n! < \sqrt{2\pi n}\left(\frac{n}{e}\right)^n e^{\frac{1}{12n}}$$

更精细的Robbins界（左右两边都比上面的紧）：

$$\sqrt{2\pi n}\left(\frac{n}{e}\right)^n e^{\frac{1}{12n+1}} < n! < \sqrt{2\pi n}\left(\frac{n}{e}\right)^n e^{\frac{1}{12n}}$$

如果不要根号和$\pi$这些精细常数，只关心量级，用积分放缩有

$$e\left(\frac{n}{e}\right)^n < n! < e\,n\left(\frac{n}{e}\right)^n$$

或者再粗糙一点，初等裂项给

$$\left(\frac{n}{2}\right)^{n/2} < n! < n^n$$

事实上我们可以发现，斯特林上下界本质上就是控制余项$\delta$；想要更紧的上下界，等价于把级数$\sum_{k=1}^{n-1}\frac1{k^2}$的余项估计得更精确，也就是把欧拉-麦克劳林展开多保留几项。另外，从上式还能看出$n!$介于$(n/e)^n$和$n^n$之间，且更靠近前者。
