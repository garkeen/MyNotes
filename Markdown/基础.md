

markdown语言基础
----------

#### 1.标题

在源代码中写入如下代码可以生成标题

```
markdown
==
（等号大于一个）最高阶标题
typora
--
（减号大于一个）次高阶标题
```

效果展示

markdown
==
typora
--

#### 2.副标题

写入如下代码生成1-6级标题 没有7级及以上

```
# h1
## h2
### h3
#### h4
##### h5
###### h6
```

效果展示

# h1

## h2
### h3
#### h4
##### h5
###### h6
#### 3.字体

```
*这是倾斜*
_这也是倾斜_
（倾斜的效果是一样的 同理加粗也是）
**这是加粗**
__这也是加粗__

***这是加粗倾斜***
~~这是加删除线~~
```

效果展示

*这是倾斜*
_这也是倾斜_

**这是加粗**
__这也是加粗__

***这是加粗倾斜***
~~这是加删除线~~

#### 4.转义字符

输入正常的符号而不被当成关键字 加入\即可

```
\# \*
```

\# \* 

#### 5.分割线

以下代码单独出现在一行均能生成相同的分割线

```
* * *
***
- - -
---
___
_ _ _
```

效果展示

* * *
***
- - -
---
___
_ _ _

#### 6.引用

```
> 这是引用
> > 引用的引用
```

效果展示

> 这是引用
>
> > 引用的引用
