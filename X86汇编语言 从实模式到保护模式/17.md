## 机器指令的格式和操作尺寸

一定要区分机器指令和汇编指令

操作码

F4 hlt

FA cli

操作码 + 立即数

B003 mov al,03

注意，每个寄存器都有单独的mov指令

操作码 + ModR/M[ mod+ reg + r/m ]

88C8 mov al,cl

8b08 mov al,[bx+si]

操作码 + ModR/M + SIB [scale + index + base]

031458 add eax,[eax+ebx*2]

前缀 + 指令

8917 mov [bx],dx

2e8917 mov [cs:bx],dx

A5 movsw

F3A5 rep movsd

不同的汇编指令可能会有相同的机器指令，需要指定这个汇编指令工作在什么操作尺寸下

具有8位操作数的指令不会和其他指令重复 但是16位 32位就可能会重复

32位处理器有16/32位操作尺寸  通过（D/B位）确定

同一时刻只有一个默认操作尺寸 如果执行的指令的操作尺寸和当前默认不同 需要加前缀66反转数据操作尺寸 67反转地址操作尺寸

伪指令bits 用于提示后面的汇编指令使用什么操作尺寸 可以控制汇编器行为

bits 16

## 开启保护模式后加载并生效新的段描述符

置PE为1后，当前的段寄存器会被当成段选择子，如果不及时修改，会导致语义错误，所以需要一次远跳转来使得段描述符生效

jmp 描述符选择子：段内偏移量
