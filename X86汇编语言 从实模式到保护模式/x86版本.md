## X86标准划分

### 16位 x86 架构

| **架构/处理器**    | **核心新增特性与机制**                                       | **寻址能力**   | **硬件代表**           |
| ------------------ | ------------------------------------------------------------ | -------------- | ---------------------- |
| **8086 / 8088**    | 基础 16 位架构、实模式（Real Mode）、段寄存器内存分段机制    | 20 位（1 MB）  | Intel 8086, Intel 8088 |
| **80186 / 80188**  | 优化指令集（引入 `PUSHA`/`POPA`, `BOUND`, `ENTER`/`LEAVE`）、集成外设控制器 | 20 位（1 MB）  | Intel 80186            |
| **80286** (`i286`) | **16 位保护模式**（Protected Mode）、硬件级多任务支持、内存保护机制 | 24 位（16 MB） | Intel 80286            |

### 32位 x86 架构 (IA-32)

| **架构名** | **核心新增指令集与微架构特性**                               | **对应硬件代表**                              |
| ---------- | ------------------------------------------------------------ | --------------------------------------------- |
| **`i386`** | 32位通用寄存器与寻址、平坦内存模型、虚拟 8086 模式、**页式内存管理（分页）** | Intel 80386                                   |
| **`i486`** | 片上集成 FPU（仅 DX 版）、5级流水线、8KB L1 Cache、新增 `CMPXCHG`、`BSWAP`、`INVD`/`WBINVD` | Intel 80486                                   |
| **`i586`** | 超标量双流水线架构（P5）、`RDTSC`、`CPUID` 标准化、后期引入 **MMX** 指令集 | Intel Pentium, AMD K5/K6                      |
| **`i686`** | **乱序执行（OOO）**、`CMOV` 条件传送、`FCMOV` 浮点条件传送、**PAE（物理地址扩展）**、后期引入 SSE | Intel Pentium Pro / II / III, AMD Athlon (K7) |

### 64位 x86 架构 (x86-64 / AMD64 / Intel 64)

> 选型基准参照 x86-64 Microarchitecture Levels (psABI v1-v4) 规范。

| **架构名**      | **核心必选特性集合**                                         | **对应硬件世代起点**                                         |
| --------------- | ------------------------------------------------------------ | ------------------------------------------------------------ |
| **`x86-64-v1`** | Long Mode（64位长模式）、NX bit（非执行位）、MMX、SSE、SSE2、CMOV、CX8、SEP、TSC、PAE | AMD K8 (Athlon 64 / Opteron)  Intel Pentium 4 64位 (Prescott-64) / Core 2 |
| **`x86-64-v2`** | **v1 全部** + SSE3、SSSE3、SSE4.1、SSE4.2、POPCNT、CX16 (`CMPXCHG16B`)、LAHF/SAHF | Intel Nehalem / Westmere  AMD Bulldozer / Jaguar             |
| **`x86-64-v3`** | **v2 全部** + AVX、AVX2、FMA、BMI1、BMI2、LZCNT、F16C、**MOVBE**、XSAVE/OSXSAVE | Intel Haswell / Broadwell  AMD Zen 1 / Zen 2 / Excavator     |
| **`x86-64-v4`** | **v3 全部** + AVX512F、AVX512DQ、AVX512CD、AVX512BW、AVX512VL | Intel Skylake-X / Ice Lake / Tiger Lake  AMD Zen 4 / Zen 5   |



## CPUID指令与特性标志

### 标准功能叶（Standard Leaves）

CPUID指令，根据eax和ecx的输入，输出到eax ebx ecx edx

#### 1. 输入：`EAX = 0`

- 输出EAX：最大支持标准功能号
- 输出EBX/EDX/ECX：拼接为CPU厂商标识字符串（无特性flag）

#### 2. 输入：`EAX = 1`

- 输出EAX：CPU版本信息（系列/型号/步进）
- 输出EBX：APIC ID、逻辑核数、缓存行参数
- 输出ECX：特性flag位图
- 输出EDX：特性flag位图

### 扩展功能叶（Extended Leaves, 0x800000xx）

#### 1. 输入：`EAX = 0x80000000`

- 输出EAX：最大支持扩展功能号
- 输出EBX/EDX/ECX：拼接为CPU厂商标识字符串（无特性flag）

#### 2. 输入：`EAX = 0x80000001`

- 输出EAX：扩展CPU版本信息
- 输出EBX：品牌索引/保留
- 输出ECX：特性flag位图
- 输出EDX：特性flag位图
