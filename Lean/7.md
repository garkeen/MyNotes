### 一个值的类型到底是什么

这里有一个问题，在DTT中写ADT，你定义变量是先写构造器，还是先标注类型？

先标注类型的话，对于(n:Nat) -> (a:type) -> vect a f(n) ->vect a g(n) 来说 你相当于需要手动标注g(n)，这很抽象

先标注构造器的话，对于下面的情况

inductive Sum (α : Type) (β : Type) : Type where 
| inl : α → Sum α β 
| inr : β → Sum α β

会发现单单的构造器无法提供完整的β信息，但这里其实应该不能这样定义，必须

inl : (α:type) →(β:type)→ α→ Sum α β 

这样就行了

好了，让我们捋一捋，仔细想一想，这到底意味着什么

这意味着，我们必须通过构造器的输入决定的值的类型

虽然我们说构造器是形式函数，但它没有实现，就像一个构造器c：Nat->Nat，但是不可能有函数的实现

考虑另一种情况，一个函数f =\x -> x+1 我们默认加法只对Nat有效，那么f：Nat->Nat

所以函数f和构造器c不同，函数f有具体实现\x -> x+1，构造器c没有

但是另一个方面，构造器看起来像函数，它接收一系列的参数，最后包装为一个类型表达式，如vect a g(n)

也就是说，也就是说，也就是说

构造器的类型，定义了一个值的类型是如何被计算出来的

另一句话来说，一个值的类型到底是什么，由构造器定义的计算式决定

### 参量与索引

```
inductive Vect (α : Type u) : Nat → Type u where   
| nil : Vect α 0   
| cons : α → Vect α n → Vect α (n + 1)
```

α是参量，Nat是索引

归纳类型的宇宙层级可以与参量相同，但必须比其索引更大，这种限制是为了确保 Lean 除了作为编程语言还可以作为定理证明器

注意，参量是α，不是α的类型Type u,显然参量不必是类型，比如(α : Nat)

### Tarski 风格的宇宙（universes à la Tarski）

如果我们想要自定义一个类型宇宙，比如，只有Nat，Bool,String呢？

我们可以通过归纳类型编码，然后写一个解释函数

```
inductive Utype where  
| nat 
| bool
| string

abbrev Utype.asType (code : Utype) : Type :=
  match code with
  | .nat => Nat
  | .bool => Bool
  | .string => String
  这里.是Utype.的缩写
```

这样我们就可以限制类型类多态允许的类型
