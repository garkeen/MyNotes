## 函数

def function (arg1:type) (arg2:type) (arg3:type) : type := expr with args

### 签名与类型

函数的**签名**包括函数名 参数类型与参数名 返回类型 如

def ad (n1:Nat) (n2:Nat) :Nat :=n1+n2

\#check ad

=>ad (n1 n2 : Nat) : Nat

函数的**类型**就是只有输入和输出类型

\#check (ad)

=>ad : Nat → Nat → Nat

当然是允许部分应用的
