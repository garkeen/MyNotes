### 编译和链接

gcc支持.c文件和.S文件的编译

.c文件就是c语言编写的文件 会被编译为.o文件 

.S文件就是带 C 预处理的汇编源文件（ assembler-with-cpp ）

.s就是纯粹的汇编文件

.s和.S的汇编默认使用 AT&T 语法，而不是nasm 的 .asm 文件的 Intel 语法

$$
.c \overset{\text{预处理}}{\implies}.i\overset{\text{编译}}{\implies}.s\overset{\text{汇编}}{\implies}.o \overset{\text{链接}}{\implies}.exe,.elf等目标操作系统可执行程序
$$
链接器干的事情就是确定各个符号在各自段下的段偏移！！！

链接器不会给出段基址！！！

最终给出段基址的是操作系统！！！



使用**lds文件**来描述目标文件的内存布局

```
SECTIONS{
.=0x1000
	.text:{}
.
	.rodata:{}
	.data:{}
	.bss:{}
}
```



### 平坦模型和分段模型

符号最终的线性地址（虚拟地址） = 段基址 + 段链接基址 + 段内偏移

分段模型下，各个段天然隔离（段基址不同），各个段的链接基址（也就是相对于段基址的基本偏移）完全可以是0

平坦模型下，段基址默认是0，那么为了隔离这些段，链接器就需要使用不同的段链接基址





只要 C 里是非static 的全局符号，.S里就能当符号名用，比如

int **b** = 3;

struct gdt_table  **_gdt_table** = ....;

int **foo**(void);



注意：gcc和clang都是默认生成32/64位的**保护模式**的x86代码
