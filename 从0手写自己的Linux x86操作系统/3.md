### 中断处理函数

除了设置IDT表 肯定还需要写对应的中断处理函数

int 0x80指向系统调用入口函数/系统调用分发函数

注意 中断触发返回后会重新执行触发该中断的代码 因此如果你的中断处理程序无法阻止这个代码继续触发该中断，那么就会循环，比如除0异常，如果你直接返回，就会继续触发，返回，死循环

编写中断处理函数 可能需要用到异常栈的信息 那么你C函数如何获取栈信息？

可以先汇编压入当前栈指针然后调用C函数 C函数参数接口写一个变量 

其实就是汇编手工传入参数然后调用 这样C函数就可以用参数获取栈





### 初始化中断控制器

**内部异常** 和 **软件中断** 都不走中断控制器 **外部硬件中断** 走中断控制器 所以实现外部硬件中断 需要初始化

8259 PIC/APIC 只谈8259

按顺序写ICW1→ICW2→ICW3→ICW4这四个初始化命令字

**ICW1**‌：设置触发方式（边沿/电平）、单片或级联、是否需要ICW4。D4位固定为1，是ICW1的标识位。

‌**ICW2**‌：设置中断向量基址。高5位由ICW2决定，低3位由8259A根据IR编号自动填充，所以基址必须是8的倍数。

‌**ICW3**‌：仅级联时写入。主片按位图写（哪几位接从片），从片按编号写（接在主片哪个IR上）。

‌**ICW4**‌：设置8086/8088模式、自动EOI、缓冲模式、特殊全嵌套等。x86平台D0位（μPM）必须置1

### 双重故障和三重故障

x86 定义了三类异常（Exception）：故障（Fault）、陷阱（Trap）和终止（Abort）

以下异常组合组合触发 DF(double fault)：

| 第一个异常正在处理时 | 紧接着发生           | 结果               |
| -------------------- | -------------------- | ------------------ |
| 任何异常             | **Fault 类异常**     | → **Double Fault** |
| Abort 类异常         | 任何异常             | → **Double Fault** |
| Trap / Interrupt     | Fault / Abort / Trap | 正常嵌套处理       |

（Fault 类：#DE, #TS, #NP, #SS, #GP, #PF, #AC, #CP 等；Abort 类：#MC；Trap 类：#OF, #BP, #DB 等）

这个操作由译码阶段的 delivery engine 完成
