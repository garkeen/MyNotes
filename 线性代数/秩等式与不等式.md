
### 基础预备
#### 核心定义
- 秩：$ \text{r}(A) = \dim C(A) = \dim R(A) $（列空间/行空间的维度，转置不改变维度）
- 列空间：$ C(A) = \{Ax \mid x \in \mathbb{F}^n\} \subseteq \mathbb{F}^m $（A的列向量线性组合）
- 行空间：$ R(A) = C(A^T) \subseteq \mathbb{F}^n $（A的行向量线性组合）
- 零空间：$ N(A) = \{x \in \mathbb{F}^n \mid Ax = 0\} \subseteq \mathbb{F}^n $（$ Ax=0 $的解空间）
- 子空间和：$ U+V = \{u+v \mid u \in U, v \in V\} $（两子空间所有向量和的集合）
- 商空间：$ V/U = \{v+U \mid v \in V\} $（U看作“零向量”后的等价类集合，维度公式：$ \dim(V/U) = \dim V - \dim U $）

#### 核心工具
- 工具1（和空间维度公式）：$ \dim(U+V) = \dim U + \dim V - \dim(U \cap V) $
- 工具2（秩-零度定理）：$ \text{r}(A) + \dim N(A) = n $（$ A \in \mathbb{F}^{m \times n} $，定义域维度=列空间维度+零空间维度）
- 工具3（子空间包含性质）：若$ U \subseteq V $，则$ \dim U \leq \dim V $，且$ \dim(V/U) = \dim V - \dim U \geq 0 $
- 工具4（矩阵运算与空间关系）：
  - $ C(AB) \subseteq C(A) $（AB的列是A列的线性组合）
  - $ R(AB) \subseteq R(B) $（AB的行是B行的线性组合）
  - $ C(A+B) \subseteq C(A)+C(B) $（A+B的列是A列与B列的和）
  - $ N(A^T A) = N(A) $，$ N(A A^T) = N(A^T) $（关键等价关系，用于补充证明）



### 核心秩等式证明

#### $ \text{r}(A) = \text{r}(A^T) $
- 证明：$ \text{r}(A) = \dim C(A) $，$ \text{r}(A^T) = \dim C(A^T) = \dim R(A) $；矩阵的列空间维度与行空间维度天然相等，故$ \text{r}(A) = \text{r}(A^T) $。

#### 秩-零度定理：$ \text{r}(A) + \dim N(A) = n $（$ A \in \mathbb{F}^{m \times n} $）
- 证明：设$ \dim N(A) = k $，取$ N(A) $的一组基$ \alpha_1,...,\alpha_k $，扩充为$ \mathbb{F}^n $的基$ \alpha_1,...,\alpha_k,\beta_1,...,\beta_{n-k} $；只需证$ A\beta_1,...,A\beta_{n-k} $是$ C(A) $的基：
  - 线性无关：若$ \sum_{i=1}^{n-k} c_i A\beta_i = 0 $，则$ A(\sum c_i \beta_i) = 0 \implies \sum c_i \beta_i \in N(A) $，故$ c_i=0 $；
  - 生成$ C(A) $：任取$ Ax \in C(A) $，$ x = \sum a_i \alpha_i + \sum b_j \beta_j $，则$ Ax = \sum b_j A\beta_j $；
  故$ \dim C(A) = n-k \implies \text{r}(A) = n - \dim N(A) $，移项得证。

#### $ \text{r}(AB) = \text{r}(B) - \dim(N(A) \cap C(B)) $（$ A \in \mathbb{F}^{m \times n}, B \in \mathbb{F}^{n \times p} $）
- 证明：
  - 核心观察：$ C(AB) = A(C(B)) $（AB的列=A作用于B的列）；
  - 定义线性映射$ T: C(B) \to C(AB) $，$ T(x) = Ax $，则$ \ker(T) = N(A) \cap C(B) $（C(B)中被A映射为0的向量）；
  - 由线性映射维度公式：$ \dim C(B) = \dim \ker(T) + \dim \text{Im}(T) $；
  - 代入$ \dim C(B) = \text{r}(B) $，$ \dim \text{Im}(T) = \dim C(AB) = \text{r}(AB) $，得$ \text{r}(B) = \dim(N(A) \cap C(B)) + \text{r}(AB) $，移项得证。

#### $ \dim(C(A)+C(B)) = \text{r}(A) + \text{r}(B) - \dim(C(A) \cap C(B)) $（A,B同型）
- 证明：设$ \dim(C(A) \cap C(B)) = k $，取交集的基$ \alpha_1,...,\alpha_k $；分别扩充为$ C(A) $的基$ \alpha_1,...,\alpha_k,\beta_1,...,\beta_{\text{r}(A)-k} $，$ C(B) $的基$ \alpha_1,...,\alpha_k,\gamma_1,...,\gamma_{\text{r}(B)-k} $；只需证$ \alpha_1,...,\alpha_k,\beta_1,...,\beta_{\text{r}(A)-k},\gamma_1,...,\gamma_{\text{r}(B)-k} $是$ C(A)+C(B) $的基：
  - 线性无关：若$ \sum a_i \alpha_i + \sum b_j \beta_j + \sum c_l \gamma_l = 0 $，则$ \sum c_l \gamma_l = -\sum a_i \alpha_i - \sum b_j \beta_j \in C(A) \cap C(B) $，故$ c_l=0 $，同理$ b_j=0 $，$ a_i=0 $；
  - 生成$ C(A)+C(B) $：任取$ u+v \in C(A)+C(B) $，$ u = \sum a_i \alpha_i + \sum b_j \beta_j $，$ v = \sum a_i' \alpha_i + \sum c_l \gamma_l $，可合并为上述基的线性组合；
  故$ \dim(C(A)+C(B)) = k + (\text{r}(A)-k) + (\text{r}(B)-k) = \text{r}(A)+\text{r}(B)-k $，得证。

#### $ \text{r}(A+B) = \dim(C(A)+C(B)) - \dim\left( \frac{C(A)+C(B)}{C(A+B)} \right) $（A,B同型）
- 证明：
  - 由工具4：$ C(A+B) \subseteq C(A)+C(B) $，故可定义商空间$ \frac{C(A)+C(B)}{C(A+B)} $；
  - 由商空间维度公式：$ \dim\left( \frac{C(A)+C(B)}{C(A+B)} \right) = \dim(C(A)+C(B)) - \dim(C(A+B)) $；
  - 代入$ \dim(C(A+B)) = \text{r}(A+B) $，移项得证；
  - 结合等式4，可进一步写为：$ \text{r}(A+B) = \text{r}(A)+\text{r}(B)-\dim(C(A)\cap C(B)) - \dim\left( \frac{C(A)+C(B)}{C(A+B)} \right) $。

#### $ \text{r}(A^T A) = \text{r}(A) = \text{r}(A A^T) $
- 证明：
  - 第一步：证$ N(A^T A) = N(A) $：
    - 若$ x \in N(A) $，则$ Ax=0 \implies A^T A x = 0 \implies x \in N(A^T A) $；
    - 若$ x \in N(A^T A) $，则$ A^T A x = 0 \implies x^T A^T A x = 0 \implies (A x)^T (A x) = 0 \implies A x = 0 \implies x \in N(A) $；
  - 第二步：由秩-零度定理：$ \text{r}(A^T A) + \dim N(A^T A) = n $，$ \text{r}(A) + \dim N(A) = n $；
  - 因$ N(A^T A) = N(A) $，故$ \text{r}(A^T A) = \text{r}(A) $；
  - 第三步：证$ \text{r}(A A^T) = \text{r}(A) $：$ \text{r}(A A^T) = \text{r}((A^T)^T A^T) = \text{r}(A^T) = \text{r}(A) $（转置保秩+第一步结论），得证。



### 核心秩不等式

#### $ \text{r}(AB) \leq \min\{\text{r}(A), \text{r}(B)\} $
- 证明：
  - 上界1：由工具4，$ C(AB) \subseteq C(A) \implies \dim C(AB) \leq \dim C(A) \implies \text{r}(AB) \leq \text{r}(A) $；
  - 上界2：由工具4，$ R(AB) \subseteq R(B) \implies \dim R(AB) \leq \dim R(B) \implies \text{r}(AB) \leq \text{r}(B) $；
  故$ \text{r}(AB) \leq \min\{\text{r}(A), \text{r}(B)\} $。

#### Sylvester不等式：$ \text{r}(AB) \geq \text{r}(A) + \text{r}(B) - n $（$ A \in \mathbb{F}^{m \times n}, B \in \mathbb{F}^{n \times p} $）
- 证明：
  - 由等式3：$ \text{r}(AB) = \text{r}(B) - \dim(N(A) \cap C(B)) $；
  - 由工具3：$ N(A) \cap C(B) \subseteq N(A) \implies \dim(N(A) \cap C(B)) \leq \dim N(A) $；
  - 由秩-零度定理：$ \dim N(A) = n - \text{r}(A) $；
  - 代入得：$ \text{r}(AB) \geq \text{r}(B) - (n - \text{r}(A)) = \text{r}(A) + \text{r}(B) - n $。

#### $ \text{r}(A+B) \leq \text{r}(A) + \text{r}(B) $（A,B同型）
- 证明：
  - 由工具4：$ C(A+B) \subseteq C(A)+C(B) \implies \text{r}(A+B) = \dim C(A+B) \leq \dim(C(A)+C(B)) $；
  - 由等式4：$ \dim(C(A)+C(B)) = \text{r}(A)+\text{r}(B)-\dim(C(A)\cap C(B)) $；
  - 因$ \dim(C(A)\cap C(B)) \geq 0 $，故$ \dim(C(A)+C(B)) \leq \text{r}(A)+\text{r}(B) $；
  综上：$ \text{r}(A+B) \leq \text{r}(A)+\text{r}(B) $。

#### Frobenius不等式：$ \text{r}(AB) + \text{r}(BC) \leq \text{r}(B) + \text{r}(ABC) $（$ A \in \mathbb{F}^{m \times n}, B \in \mathbb{F}^{n \times p}, C \in \mathbb{F}^{p \times q} $）
- 证明：
  - 对$ \text{r}(AB) $用等式3：$ \text{r}(AB) = \text{r}(B) - \dim(N(A) \cap C(B)) \quad (1) $；
  - 对$ \text{r}(ABC) = \text{r}(A(BC)) $用等式3：$ \text{r}(ABC) = \text{r}(BC) - \dim(N(A) \cap C(BC)) $，移项得$ \text{r}(BC) = \text{r}(ABC) + \dim(N(A) \cap C(BC)) \quad (2) $；
  - 由工具4：$ C(BC) \subseteq C(B) \implies N(A) \cap C(BC) \subseteq N(A) \cap C(B) \implies \dim(N(A) \cap C(BC)) \leq \dim(N(A) \cap C(B)) \quad (3) $；
  - (1)+(2)：$ \text{r}(AB)+\text{r}(BC) = \text{r}(B) + \text{r}(ABC) + [\dim(N(A) \cap C(BC)) - \dim(N(A) \cap C(B))] $；
  - 由(3)，括号内项≤0，故$ \text{r}(AB)+\text{r}(BC) \leq \text{r}(B)+\text{r}(ABC) $。

#### $ \text{r}(PAQ) = \text{r}(A) $（P可逆，Q可逆）
- 证明：
  - 可逆矩阵P是“同构映射”：$ C(PA) = P(C(A)) $，映射可逆故维度不变$ \dim C(PA) = \dim C(A) \implies \text{r}(PA) = \text{r}(A) $；
  - 同理，Q可逆：$ \text{r}(AQ) = \text{r}(A^T Q^T) = \text{r}(A^T) = \text{r}(A) $（转置保秩）；
  - 故$ \text{r}(PAQ) = \text{r}(PA) = \text{r}(A) $。
