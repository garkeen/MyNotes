$F(x,y) = F_3 + F_2 + F_1 + F_0 = 0$
- $F_3$：三次齐次部分（最高次项），$F_3 = a x^3 + b x^2 y + c x y^2 + d y^3$（齐次度3）  
- $F_2$：二次齐次部分，$F_2 = e x^2 + f x y + g y^2$  
- $F_1$：一次齐次部分，$F_1 = h x + i y$  
- $F_0$：常数项  

- 辅助符号：  
  - $L$：一次齐次因式（如$x+ky$）  
  - $Q$：二次既约齐次多项式（不可分解为两个一次齐次因式）  
  - $G$：二次多项式（可既约或退化）

| 2        | $F_3$既约，$F$既约，1个结点 | 结点三次曲线（1自交点） |
| 3        | $F_3$既约，$F$既约，1个尖点 | 尖点三次曲线（1切点） |
| 4        | $F_3=L·Q$，$F$既约，1个孤立点 | 孤立点+单分支三次曲线 |
| 5        | $F_3=L·Q$，$F=L·G$（$G$既约） | 直线+椭圆/双曲线/抛物线 |
| 6        | $F_3=L·Q$，$F=L·G$（$G$退化） | 直线+两条直线（相交/平行） |
| 7        | $F_3=L_1·L_2·L_3$（三不同$L$），$F=L_1·L_2·L_3$ | 三条不共点直线 |
| 8        | $F_3=L_1·L_2·L_3$（两$L$平行），$F=L_1·L_2·L_3$ | 两条平行直线+一条相交直线 |
| 9        | $F_3=L_1²·L_2$，$F=L_1²·L_2$ | 一条二重直线+一条相交直线 |
| 10       | $F_3=L³$，$F=L³$ | 一条三重直线 |
| 11       | $F_3≡0$（三次项全零） | 退化为二次/一次/常数方程对应轨迹 |

## 二次多项式

我们发现，就算只有两个变元，次数稍微高一点就是非常深奥的理论了，因此，我们就研究次数为1和2的多元N次多项式

对于一次多项式

f(x1,x2,x3,...,xn)=c1x1+c2x2+c3x3+....+cnxn+d=0

非常简单，就是一个高维的平面

对于二次多项式

f1 -> f(x1,x2,x3,...,xn)=c1x1 ^2+c2x2 ^2+...+  cnxn^2 + d1x1x2 + d2 x1x3 + ... + e1x1 + e2x2 + ... +  enxn + f = 0

注意，这是一个隐式方程，与
f2 -> xn=f(x1,x2,...,xn-1)

描绘的图像是不等价的，是f1的特例

f2甚至无法描绘完整的椭圆，圆，双曲线，这些都是闭合的，那么y肯定不是单值，单值只能描绘一个类抛物线

因此，当我们写下

y = x^tAx的时候，如果不默认y是定值，那么这个图像永远只能是全定义域下的某个抛物型超曲面

所有的抛物型超曲面分为椭圆抛物面和双曲抛物面（马鞍面）

而使用x^tAx=constant的时候，可以而且只能描述椭圆型、双曲型超曲面，

使用x ^tAx+b ^ t x+ c = 0 才能同一描述抛物型，椭圆型，双曲型超曲面 这三者才是二次超曲面的完整分类

## 二次型
#### 二次超曲面一般形式
$$ \boldsymbol{x}^T A \boldsymbol{x} + 2\boldsymbol{b}^T \boldsymbol{x} + c = 0 $$（A 为实对称矩阵）  
- 二次部分 \( $$\boldsymbol{x}^T A \boldsymbol{x} $$\) 决定类型；  
- 一次项、常数项仅影响位置/大小，不改类型。

#### 惯性指数定义
- 经非退化线性变换，二次型标准形为 \( $$ \lambda_1 y_1^2 + \dots + \lambda_r y_r^2 $$ \)；  
- 正惯性指数 \( p \)（正特征值个数），负惯性指数 \( q \)（负特征值个数）；  
- 惯性定理：\( p、q \) 唯一，且 \( $$p + q = \text{rank}(A)$$ \)。

#### 惯性指数与超曲面类型对应（几何+代数）
| 超曲面类型 | 代数特征（惯性指数） | 几何特征 |
|------------|----------------------|----------|
| 椭圆型     | \( p+q=n \) 且 \( q=0 或  p=0 \)，满秩正定/负定 | 曲率符号统一，无实渐近线 |
| 双曲型     | \( p+q=n \) 且 \( p,q $$\geq$$ 1 \)，满秩不定 | 曲率符号混合，有实渐近线 |
| 抛物型     | \( p+q < n \)，降秩（含零特征值） | 有渐近方向，曲率符号不完整 |
