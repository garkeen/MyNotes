## 惰性求值

### Thunks

Thunk 是 Haskell 实现惰性求值的核心机制，本质上是计算过程的中间表达式



### Strickness

以fold (+) 0 [1,2,3,4]为例子

=>fold (+) (0+1) [2,3,4]

=>fold (+) ((0+1)+2) [3,4]

=>fold (+) (((0+1)+2) +3) [4]

...

首先，展开这么多项太浪费空间，如果列表一大内存直接爆炸，因此需要严格求值，或者立即求值



以fold' (+) 0 [1,2,3,4]为例子

=>fold' (+) (1) [2,3,4]

=>fold' (+) (3) [3,4]

=>fold' (+) (6) [4]

...



seq:: a->b->b

seq a b = b

seq会使得第一个a严格求值 seq是唯一一个这个性质的函数



### WHNF

Church Rosser Theorem

lambda表达式最后的求值标准形式和求值过程选择子表达式求值的顺序无关

Normal Form

不可继续求值的表达式

注意，函数的应用不会把参数严格求值，而是把参数的表达式带入

add (1+2) (3*4)

=> (1+2) + (3*4)

而不是

add (1+2) (3*4)

=>add 3 12

=>3+12

这本质是重写



一个值是WHNF 若以下情况

1.这个值的数据构造器已经知道

2.是lambda表达式

3.部分应用函数



seq也是强制到WHNF



deepseq是强制到NF
