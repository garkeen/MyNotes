## ADT

data Name = Constructor1 <args> | Constructor2 <args> | ...

注意，和Ocaml一样类型定义不依赖值，**<args>里面只能填类型**

注意，第一个参数是名字，后面是类型，不用写of（Ocaml要写）



### 递归定义

data Nat = zero | Succ Nat



### 带参数的ADT

data Name a = Cons a



## 构造器

类型定义中包含两个构造器，一个是类型构造器，一个是数据构造器

data  TypeConstructor <args> = DataConstructor1 <args> | DataConstructor2 <args>

因此，如果我们的类型显示为

f::(m a b)->c

这就意味着(m a b)才是一个完整的类型 因此m是类型构造器 a b是这个m构造器的参数 



此外

一个参数的TypeConstructor:: * -> * 表示这个构造器的类型 （类型的类型，Kind），接收一个类型参数

如果是两个？TypeConstructor1:: * -> * -> *





### 常见坑：类型构造器与数据构造器同名

data Box a= Item a|Box (Box a)

## Typeclasses类型类

本质上是实现一个受限多态函数，也就是说假如你想实现

add:: a->a->a

但是a不能是任意类型，只能是int float，那么就需要类型类来限制

比如

class Name T where

 myfunc:: T -> <expr>

定义了一个多态函数myfunc，

instance Name int where

  myfunc = \x -> x+1

instance Name String where

  myfunc = \x -> "String"

那么myfunc(1)就会调用Name int定义的实例,myfunc("N")就会调用Name String定义的实例

比如自定义类型

data Color = Red | Blue | White

我们就可以重载==这个运算符（其类型类是Eq），

instance Eq Color where

(==) Red Blue = False

(==) Red White = False

....



### 隐式派生 

如果你定义了Color的==就不需要定义 /=
