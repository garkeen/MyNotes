## Functor本质

Functor本质上是一种类型类，实现了这个类型类的类型可以称为是一个Functor

Functor 要求类型构造器的 Kind 是`* -> *`（单参数）

主要用于函数运用于盒子里面的数据

class Functor f where

​	fmap :: (a -> b) -> (f a -> f b) -- 核心操作：映射



## Applicative本质

Applicative本质上是一种类型类，实现了这个类型类的类型可以称为是一个Applicative

Applicative继承于Functor

主要用于如果函数和数据都被盒子包装的情况

Applicative要求类型构造器的 Kind 是`* -> *`（单参数）



class Functor f => Applicative f where  

​	pure  :: a -> f a    -- 核心1：纯值进容器 

​	 (<*>) :: f (a -> b) -> f a -> f b  -- 核心2：容器函数作用于容器值



## Monad本质

Monad本质上是一种类型类，实现了这个类型类的类型可以称为是一个Monad

Monad继承于Applicative

主要用于如果函数的输出带有盒子的情况

Monad 要求类型构造器的 Kind 是`* -> *`（单参数）

class Applicative m => Monad m where  

(>>=)  :: m a -> (a -> m b) -> m b  -- 核心：bind操作符 

 (>>)   :: m a -> m b -> m b         -- 忽略第一个容器的值，执行第二个  其中 m >> k = m  >>= \ _  ->  k   

return :: a -> m a                  -- 等价于Applicative的pure  return = pure

join :: m (m a)-> m a

其实实现了join就可以实现>>=

monad干的唯一一个有意义的事情就是实现join 压扁

思考

我们注意到并没有实现一个函数 m a -> a，这是非常重要的观点，这意味着把值打包为盒子其实是不可逆的
